<a href="/glossary#handle" class="wiki-link">Handle</a> returned by every `defineX`. Call `dispose()` to remove the
registration. Idempotent and synchronous — see module-level "Dispose
contract" notes.

## Public API

## Stability

experimental

```ts
import { defineSidebarTab, type DisposableHandle } from '@comfyorg/extension-api'

const handle: DisposableHandle = defineSidebarTab({
  id: 'my-tab',
  title: 'My Tab',
  type: 'vue',
  component: MyTab
})

// Later: tear down
handle.dispose()
```
