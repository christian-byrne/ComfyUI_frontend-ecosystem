Defined in: [extension-api/node.ts:57](https://github.com/Comfy-Org/ComfyUI_frontend/blob/528d014e15d500d349a7dcfdb3d5fae81b06e2dc/src/extension-api/node.ts#L57)

A 2D size as `[width, height]`.

**Immutable tuple.** Attempts to
mutate via `node.getSize()[0] = X` raise a TypeScript error. Use
<a href="/api-docs/nodehandle" class="wiki-link">NodeHandle</a>.setSize to resize the node.

```ts
import type { Size } from '@comfyorg/extension-api'

const target: Size = [320, 240]
```
