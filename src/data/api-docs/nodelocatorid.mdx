A globally unique identifier for nodes that maintains consistency across
multiple instances of the same subgraph.

Format:
- For subgraph nodes: `<immediate-contained-subgraph-uuid>:<local-node-id>`
- For root <a href="/api-docs/graph" class="wiki-link">graph</a> nodes: `<local-node-id>`

Examples:
- "a1b2c3d4-e5f6-7890-abcd-ef1234567890:123" (node in subgraph)
- "456" (node in root <a href="/api-docs/graph" class="wiki-link">graph</a>)

Unlike <a href="/api-docs/execution" class="wiki-link">execution</a> IDs which change based on the instance path,
<a href="/api-docs/nodelocatorid" class="wiki-link">NodeLocatorId</a> remains the same for all instances of a particular node.
