Cleanup function returned from a widget's `mount()`. Fires exactly once,
when the widget entity is destroyed. **Does NOT fire on host remount**
(graph↔app mode, subgraph promotion, `<KeepAlive>` shuffle) — use
[WidgetMountContext.onBeforeRemount](../interfaces/WidgetMountContext.md#onbeforeremount) / [WidgetMountContext.onAfterRemount](../interfaces/WidgetMountContext.md#onafterremount)
for those.

## Returns

`void`

experimental
