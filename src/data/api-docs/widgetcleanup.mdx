Defined in: [extension-api/widget.ts:539](https://github.com/Comfy-Org/ComfyUI_frontend/blob/528d014e15d500d349a7dcfdb3d5fae81b06e2dc/src/extension-api/widget.ts#L539)

Cleanup function returned from a widget's `mount()`. Fires exactly once,
when the widget entity is destroyed. **Does NOT fire on host remount**
(<a href="/api-docs/graph" class="wiki-link">graph</a>↔app mode, subgraph promotion, `<KeepAlive>` shuffle) — use
[WidgetMountContext.onBeforeRemount](../interfaces/WidgetMountContext.md#onbeforeremount) / [WidgetMountContext.onAfterRemount](../interfaces/WidgetMountContext.md#onafterremount)
for those.

## Returns

`void`

## Stability

experimental

```ts
import { defineWidget, type WidgetCleanup } from '@comfyorg/extension-api'

defineWidget({
  name: 'my-ext',
  type: 'STRING',
  mount(host): WidgetCleanup {
    const input = document.createElement('input')
    host.appendChild(input)
    return () => input.remove()
  }
})
```
