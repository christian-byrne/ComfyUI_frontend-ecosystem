Payload for `node.on('executed', handler)`.

Replaces the v1 `nodeType.prototype.onExecuted` patching pattern.

```ts
node.on('executed', (e) => {
  const text = e.output['text'] as string[]
  previewWidget.setValue(text.join('\n'))
})
```

## Properties

| Property | Modifier | Type | Description |
| ------ | ------ | ------ | ------ |
| <a id="output"></a> `output` | `readonly` | `Record`\<`string`, `unknown`\> | The backend <a href="/api-docs/execution" class="wiki-link">execution</a> output for this node. Shape varies by node type. |
