```ts
type AsyncHandler<E> = (event) => void | Promise<void>;
```

Defined in: [extension-api/events.ts:35](https://github.com/Comfy-Org/ComfyUI_frontend/blob/528d014e15d500d349a7dcfdb3d5fae81b06e2dc/src/extension-api/events.ts#L35)

A typed async-capable event handler. Only valid for events that explicitly
support async handling (currently only `beforeSerialize`).

## Type Parameters

| Type Parameter | Description |
| ------ | ------ |
| `E` | The event payload type. |

## Parameters

| Parameter | Type |
| ------ | ------ |
| `event` | `E` |

## Returns

`void` \| `Promise`\<`void`\>

```ts
import type { AsyncHandler, WidgetBeforeSerializeEvent } from '@comfyorg/extension-api'

const handler: AsyncHandler<WidgetBeforeSerializeEvent> = async (e) => {
  const frame = await captureFrame()
  e.setSerializedValue(frame)
}
```
